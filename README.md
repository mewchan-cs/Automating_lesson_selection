# دستیار مدیر گروه ۰٫۳٫۶ — فقط تکمیل دروس و واحدها

حالت فعال افزونه فقط بررسی می‌کند درس‌ها و سهم واحدهای عمومی، تخصصی، اختیاری و سایر دسته‌های چارت ورودی تکمیل شده‌اند یا نه. مشروطی، الف، سقف واحد و معدل تابستان از این گزارش جدا شده‌اند. جدول دسته‌ها، درس‌های الزامیِ باقی‌مانده و اختلاف‌های مؤثر در شمارش نمایش داده می‌شوند. راهنمای فعلی در GRADUATION_ONLY.md است؛ متن‌های بعدی سابقه قابلیت‌های نسخه‌های قبلی‌اند و حالت فعال فعلی را تعیین نمی‌کنند.

اصلاح نمایش ورودی ۱۴۰۱–۱۴۰۲: گروه‌های «انقلاب اسلامی / اندیشه سیاسی امام» و «تاریخ تحلیلی اسلام / تاریخ امامت» اکنون در فهرست اصلی هم دیده می‌شوند، با توضیح اینکه گذراندن یکی از گزینه‌ها کافی است. قبولی یک گزینه با نمره ۱۰ یا بالاتر گروه را تکمیل می‌کند؛ صرف اخذ، مردودی یا نمره خالی باعث تکمیل فرضی نمی‌شود. گروه تکمیل‌شده دوباره به‌عنوان درس لازم پیشنهاد نمی‌شود.

بررسی به‌صورت پیش‌فرض فعال است و ابتدا یک جمله نشان می‌دهد: وضعیت و سقف واحد، ترم آخر با معافیت، یا تکمیل دروس چارت. برنامه مرجع دو تصویر قابل تطبیق تکمیل شده و گزینه‌ها بدون شمارش دوباره بررسی می‌شوند. در تصویر ۱۴۰۳ اختلاف واقعی جمع واحد وجود دارد؛ وضعیت معدل جداگانه اعلام می‌شود ولی حکم تکمیل برنامه با این منبع صادر نمی‌شود. توضیح بازخوانی، حدود تأیید و نمونه‌های آزمون در AUTO_REVIEW.md است. مطالب بعدی جزئیات نسخه‌های پیشین و تنظیمات جایگزین‌اند.

گزینهٔ جدید «بررسی فارغ‌التحصیلی، وضعیت معدل و سقف واحد» اضافه شده است. طبق قواعدی که شما مشخص کردید، معدل آخرین ترم کمتر از ۱۲ سقف ۱۴، از ۱۲ تا کمتر از ۱۷ سقف ۲۰ و از ۱۷ به بالا سقف ۲۴ واحد دارد. ترم آخر با حداکثر ۲۴ واحد ماندهٔ تأییدشده، معافیت پیش‌نیاز و هم‌نیاز دارد. برای فعال‌شدن قطعی بررسی فارغ‌التحصیلی و استثنای ترم آخر، جدول کامل الزامی‌ها و سهم گروه‌ها باید تکمیل شود؛ این اطلاعات از روی خانه‌های مبهم حدس زده نشده‌اند. جزئیات در ACADEMIC_RULES.md است.

این نسخه بر پایهٔ ۰٫۳ ساخته شده است. بالای گزارش آشنای همان نسخه، دو بخش کوتاه اضافه شده‌اند:

- نام و کد درس‌های چارت تصویری که در کارنامهٔ موجود سابقه اخذ ندارند.
- برای خانه‌های «اختیاری»، «تخصصی»، «تمرکز» و گزینه‌های /، فهرست درس‌های اخذنشدهٔ جدول مربوط به همان ورودی. گزینه‌های آماده از نظر پیش‌نیاز جدا هستند؛ موارد نیازمند بررسی یا پیش‌نیاز در بخش بازشونده قرار دارند.

اطلاعات در موتور ذخیره شده و به حافظه گفت‌وگو وابسته نیست. تصاویر، ترتیب ترم‌ها، روابط و نگاشت دسته‌ها در backend/visual_data نگه‌داری می‌شوند. برای مشاهده توضیح منبع و تنظیم قاعده قبولی، backend/visual_data/README.md را ببینید.

## نصب

۱. بسته را استخراج کنید؛ موتور قبلی را ببندید و start_server.bat همین بسته را اجرا کنید. Python 3.10 یا جدیدتر لازم است و موتور بسته اضافی نیاز ندارد.

۲. در chrome://extensions، Developer mode را فعال کنید و با Load unpacked پوشه extension این بسته را انتخاب کنید. اگر همان پوشه نصب قبلی را جایگزین کرده‌اید، Reload را بزنید.

۳. کارنامه را با حساب مجاز در پرتال باز کنید؛ از آیکون افزونه، کد اتصال و چارت سال ورودی را وارد کنید و «استخراج و تحلیل» را بزنید.

تصویر اول برای ۱۴۰۱ و ۱۴۰۲، تصویر دوم طبق تأیید شما برای ۱۴۰۳ به بعد و تصویر سوم برای ۱۳۹۵–۱۴۰۰ گرایش نرم‌افزار است. چارت از روی اولین سال کارنامه حدس زده نمی‌شود.

## نکات نتیجه

«اخذنشده» یعنی در کارنامه موجود سابقه اخذ ندارد؛ درس مردود یا بی‌نمرهٔ قبلی در این فهرست نمی‌آید و این به معنی قبولی آن نیست. سهم باقی‌ماندهٔ اختیاری/تمرکز از تعداد خانه‌ها یا یک اخذ قبلی حدس زده نمی‌شود. کد نامطمئن یا نام یکسان با کد متفاوت در «تطبیق‌های نامطمئن» می‌آید.

تصویر ۱۴۰۳ کد ندارد؛ کدهای نمایش‌داده‌شده آن از داده قبلی‌اند و با تصویر تأیید نشده‌اند. کد مفقود عمومی‌ها و پروژه ساخته نمی‌شود. حد قبولی همه درس‌ها طبق تأیید شما ۱۰ است؛ در نبود مدرک قبولی، گزینهٔ دارای پیش‌نیازِ نامشخص، پیشنهاد آماده محسوب نمی‌شود. هم‌نیازهای پیشنهادی باید با هم اخذ شوند.

## آزمون

از پوشه academic_advisor_mvp:

```powershell
python -m unittest discover -s tests -p test_visual_summary.py -v
python -m unittest discover -s tests -p test_backend.py -k AnalyzerTests -v
node tests/test_chart_summary_view.js
node --check extension/chart-summary.js
node --check extension/popup.js
```

۲۱ آزمون جدید خلاصه، ۵ آزمون تحلیل قبلی و آزمون نمایش موفق بوده‌اند. Node فقط برای آزمون JavaScript لازم است. سناریوی ناشناس tests/visual_demo_transcript.json و خروجی tests/visual_demo_report.json همراه بسته‌اند.

آزمون اتصال واقعی HTTP و نصب/نمایش در Chrome این نوبت اجرا نشده است. محدودیت و رد مجوز اتصال محلی نوبت قبلی برقرار است؛ سرور و استخراج‌کننده تغییر نکرده‌اند. قالب فعلی استخراج همان جدول پنج‌ستونی اطلاعیه نمرات است و قالب دیگر پرتال نیازمند بررسی نمونه مجاز است.

API محلی توکن‌دار حفظ شده و دو گزینه academic_review و target_term برای بررسی جدید می‌پذیرد؛ هیچ کارنامه یا نتیجه‌ای به داده پایه اضافه یا خودکار روی دیسک ذخیره نمی‌شود. مسیر API جدید با جریان بایت در حافظه و بدون اتصال شبکه آزموده شده است. وضعیت تحویل در CHECKPOINT.md و راهنمای تاریخی نسخه پایه در README_0.3.md قرار دارد.
