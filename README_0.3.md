# نسخه بازطراحی‌شده ۰٫۳

این نسخه بازسازی جدید بر پایه نمونه اولیه است، نه فایل بازیابی‌شده Work.

- فونت وزیرمتن به‌صورت محلی داخل افزونه، متن بزرگ‌تر و ظاهر تازه
- جزئیات بازشونده هر نیمسال، جدول کامل نمرات و کد درس‌ها
- جستجوی نام و کد درس، فیلتر وضعیت و روند معدل اعلام‌شده سامانه
- توضیحات آماری و چاپ / ذخیره PDF با باز شدن همه نیمسال‌ها
- حالت صفحه بزرگ: ابتدا روی آیکون افزونه در تب کارنامه کلیک کنید و «باز کردن در صفحه بزرگ» را بزنید. همان تب کارنامه را باز نگه دارید.

وضعیت «پاس‌شده / افتاده» دسته‌بندی نمایشی بر پایه نمره ۱۰ است؛ وضعیت رسمی در منبع موجود نیست. نمره خالی به‌عنوان بدون نمره نمایش داده می‌شود. معدل‌های رسمی از سامانه نقل می‌شوند. هر اخذ تکراری جداگانه حفظ شده است.

فونت ایران‌سنس همراه بسته نیست. برای استفاده از نسخه دارای مجوز خودتان، فایل فونت و تعریف font-face آن را جایگزین وزیرمتن کنید.

## راهنمای نسخه پایه و نصب

# نمونه اولیه دستیار مدیر گروه (افزونه کروم + موتور تحلیل محلی)

این نسخه، **کارنامهٔ بازشده** در پرتال دانشگاه را با کلیک مدیر گروه از جدول‌های HTML استخراج می‌کند، آن را به موتور محلی پایتون می‌فرستد و گزارش اولیه برمی‌گرداند. نیازی به API هوش مصنوعی، اینترنت برای تحلیل، یا نصب پکیج‌های پایتون نیست.

> این نمونه اولیه بر اساس HTML صفحهٔ **«اطلاعیه نمرات»** ساخته شده است. هنوز HTML کارنامهٔ پنل مدیر گروه بررسی نشده؛ چنانچه جدول‌های پنل متفاوت باشند، لازم است استخراج‌کننده را برای آن صفحه تطبیق دهیم. افزونه تنها اطلاعات کارنامه‌ای را می‌خواند که کاربر **با مجوز خودش باز کرده**، نه فهرست همهٔ دانشجویان.

## گام اول — روشن‌کردن موتور محلی

- روی ویندوز: فایل `start_server.bat` را اجرا کنید (یا در پوشه پروژه دستور `python backend/server.py`).
- لینوکس / مک: دستور `python3 backend/server.py` را اجرا کنید.
- پایتون **نسخه 3.10 یا جدیدتر** لازم است. موتور فقط با کتابخانه استاندارد پایتون کار می‌کند.
- پنجره بازشده را **باز نگه دارید**. در آن، نشانی `http://127.0.0.1:8765` و یک **کد اتصال موقت** نمایش داده می‌شود. این کد را فقط در افزونه وارد کنید؛ آن را در سایت یا پیام دیگر وارد نکنید.

## گام دوم — نصب افزونه Google Chrome

1. فایل ZIP را از حالت فشرده خارج کنید.
2. در کروم، آدرس `chrome://extensions` را باز کنید.
3. گزینه `Developer mode` را روشن کنید.
4. روی `Load unpacked` بزنید و **پوشه `extension`** را انتخاب کنید، نه فایل ZIP و نه پوشه `backend`.
5. صفحهٔ کارنامهٔ یک دانشجو را در پرتال باز کنید و آن را در زبانهٔ فعال نگه دارید. از حساب مجاز خودتان استفاده کنید.
6. روی آیکون افزونه «دستیار مدیر گروه» کلیک کنید. **کد اتصال** را از پنجرهٔ پایتون وارد کنید.
7. چارت مربوط به سال ورود دانشجو را **به‌صورت دستی و آگاهانه** انتخاب کنید: `1395-1400`، `1401-1402` یا `1403-plus`.
8. دکمه «استخراج و تحلیل کارنامه باز» را بزنید.

پس از چند لحظه گزارش اولیه داخل افزونه نمایش داده می‌شود؛ شامل تعداد نیمسال‌ها، دفعات اخذ درس، مجموع واحدهای اخذشده، معدل و واحدهای قبول‌شده **به نقل از سامانه**، درس‌های تکراری و کدهای نامنطبق با چارت. با دو دکمهٔ پایین صفحه می‌توانید گزارش یا کارنامهٔ استخراج‌شده را به شکل `JSON` ذخیره کنید.

## این نمونه چه چیزی را **هنوز** تحلیل نمی‌کند؟

قوانین آموزشی هنوز از طرف مدیر گروه/دانشگاه دریافت نشده‌اند، بنابراین **نمره زیر ۱۰ صرفاً در آمار نشان داده می‌شود** و از آن، مردودی قطعی، امکان انتخاب واحد، معادل‌سازی یا فارغ‌التحصیلی استنتاج نمی‌شود. موتور روی کد رسمی درس با چارت انتخابی تطبیق **دقیق** می‌دهد؛ شناسه‌های یکسان در چارت‌های مختلف ممکن است همچنان نیازمند تأیید هم‌ارزی باشند. گزارش برای تصمیم‌های رسمی آموزشی کافی نیست.

سال ورود رسمی دانشجو در نمونه «اطلاعیه نمرات» وجود ندارد؛ سال اولین نیمسال فقط تخمین است و **هیچ چارت خودکار از روی این تخمین انتخاب نمی‌شود**. مدیر گروه باید چارت صحیح را انتخاب کند.

## معماری

```text
Chrome (صفحه کارنامه باز در تب / iframe)
     │ کلیک مدیر گروه؛ استخراج فقط متن جدول‌های موجود
     ▼
extension/extractor.js (ساختار استاندارد transcript JSON)
     │ ارسال HTTPS? خیر، HTTP فقط روی loopback رایانه کاربر
     ▼
http://127.0.0.1:8765/analyze
     │ کد اتصال موقت + بررسی origin + محدودیت حجم
     ▼
backend/server.py → backend/analyzer.py → backend/curriculum_engine.py
     │ داده‌های اصلی سه چارت در backend/data/*.json
     ▼
گزارش اولیه در خود افزونه + امکان ذخیره JSON
```

## نکات محرمانگی و دسترسی

- اطلاعات به هیچ سرور بیرونی ارسال نمی‌شود؛ `127.0.0.1` فقط روی رایانهٔ فعلی در دسترس است.
- موتور به آدرس loopback محدود است؛ هر بار اجرا یک کد اتصال تصادفی تولید می‌کند و درخواست افزونهٔ مرورگر با آن احراز می‌شود.
- کد اتصال فقط در **حافظه نشست افزونه** نگه‌داری می‌شود؛ مرورگر آن را به خود صفحهٔ پرتال نمی‌دهد.
- سرور کارنامه‌ها را روی دیسک ذخیره نمی‌کند و بدنهٔ درخواست‌ها را در لاگ چاپ نمی‌کند؛ فایل‌های JSON فقط با انتخاب خود کاربر دانلود می‌شوند.
- گزارش و فایل خروجی حاوی نام/شماره دانشجو هستند؛ آن‌ها را در محل امن ذخیره کنید.
- سامانه ممکن است نمای ویژه مدیر گروه متفاوتی داشته باشد و افزونه ممکن است در آن نما نتواند کارنامه را پیدا کند؛ این یک محدودیت اعلام‌شده است.
- هیچ خزیدن خودکار، جمع‌آوری مخفی یا دور زدن ورود/مجوز پیاده‌سازی نشده است.

## آزمون‌ها

آزمون موتور (بدون بسته اضافی):

```bash
python -m unittest discover -s tests -p "test_backend.py" -v
```

آزمون اختیاری استخراج از نمونهٔ HTML ناشناس‌شده (در محیطی که `playwright` و مرورگر Chromium نصب است):

```bash
python tests/test_browser_extractor.py
```

در فایل `tests/demo_report_anonymous.json` نمونه گزارش خروجی ناشناس‌شده قرار دارد. این فقط برای آزمایش و بررسی ساختار داده است؛ هرگز نباید به عنوان تأیید قوانین آموزشی استفاده شود.

## رفع مشکل رایج

- **کد اتصال اشتباه است:** آن را دقیقاً از پنجرهٔ جدید پایتون کپی کنید؛ بعد از راه‌اندازی مجدد کد تغییر می‌کند.
- **موتور در دسترس نیست:** ابتدا `start_server.bat` را اجرا کنید. اگر پورت 8765 توسط برنامه دیگری استفاده می‌شود، آن برنامه را ببندید.
- **کارنامه پیدا نشد:** مطمئن شوید صفحهٔ «اطلاعیه نمرات» واقعاً باز و بارگیری شده است؛ اگر صفحهٔ مدیر گروه شکل دیگری دارد، یک نمونه HTML ناشناس‌شده از همان قسمت لازم است.
- **کد درس در چارت پیدا نشد:** سال ورودی/چارت انتخابی را بررسی کنید؛ موتور بر اساس شباهت عنوان فارسی تطبیق دلخواه انجام نمی‌دهد.
